# Section 5 — Milestone Content

**Source:** PDF Pages 22–24  
**Note:** PDF documents **sample** milestones. Full guide lists 23 — remaining TBD when extended PDF/pages arrive.

Each milestone has:
- `whatThisMeans` — shown on story screen to parent
- `storyPrompt` — sent to Claude API with `[variables]` replaced

## Documented milestones

### The First Smile (Month 6–8)
- **Means:** Beginning of social communication; expressions affect the world.
- **Prompt vars:** parent_name, child_name, age_months, who_witnessed, time_of_day, mood

### The First Word (Month 10–14)
- **Means:** Language unlocked; vocabulary explosion beginning.
- **Prompt vars:** same as above

### The Explorer / Crawling (Month 7–9)
- **Means:** First act of independence; confidence in own body.
- **Prompt vars:** same

### The Walker / First Steps (Month 12–15)
- **Means:** Courage to let go and trust body — not just physical steps.
- **Prompt vars:** same

### The Pointer (Month 9–12)
- **Means:** Sharing inner world; beginning of true communication.
- **Prompt vars:** same

### The Laugher (Month 3–5)
- **Means:** Timing, surprise, shared joy; foundation of humour.
- **Prompt vars:** same

### The Emotion Namer (Month 28–32)
- **Means:** Naming feeling = learning to manage it.
- **Prompt vars:** same

### The Big Kid (Month 36)
- **Means:** End of baby years; brain ~80% adult size.
- **Prompt:** 4-paragraph journey summary to preschool
